AUTOMATION GUIDE

开启自动文献推送

项目已带有定时脚本与 GitHub Actions 配置。上传 GitHub 后，完成以下设置：

  1. 在 Repository Settings → Secrets 添加 OPENALEX_API_KEY（推荐但非必须）
  2. 在 Settings → Pages 开启 GitHub Pages（Deploy from branch，选择 main / root）
  3. 若需邮件推送，再添加 SMTP 相关 Secrets
  4. 在 Actions 运行一次 Update literature radar
